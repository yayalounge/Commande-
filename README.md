# commande.yaya-lounge.fr

Page de commande à table du Yäya Lounge (GitHub Pages). Le client scanne le QR de sa table, choisit, envoie :
la commande arrive dans l'appli YÄYA Service, où l'équipe la valide.

Source et tests : dépôt `yayalounge/yaya`, dossier `commande/site/`. Ne pas modifier ici à la main : recopier depuis là-bas.
